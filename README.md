## Local Development

Requirements: Node.js and npm (we recommend installing Node via nvm)

Steps:

```sh
# 1) Clone the repository
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>

# 2) Install dependencies
npm install

# 3) Start the dev server
npm run dev
```
